# PIXEL-typing-speed-and-accuracy-tester
Type fast. Look cool. Embrace the neon.

* Pixel-Perfect UI: Hand-crafted retro typography, crisp borders, and a glowing neon color palette (Cyan #00f0ff & Hot Pink #ff007f).
* Real-Time Analytics: Track your WPM, raw speed, accuracy percentage, and error counts live as you type.
* Immersive Atmosphere: Retro CRT scanline vibes, arcade-style sound effects (optional), and smooth animations.
* Lightweight & Fast: Built with vanilla web tech (or update this to your stack!) for instant loading times and zero bloat.

  built with HTML5, CSS and JavaScript
